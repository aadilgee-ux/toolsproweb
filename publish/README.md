# Publish Guide

## Static Pages - Blogger par publish karne ka tareeqa

Har file ke liye:

1. Blogger Dashboard > **Pages** > **New Page**
2. Title: file ke naam se (neeche table dekhein)
3. Editor mein **HTML view** (upar pencil icon > HTML view) par switch karein
4. Is folder ki file khol kar **poora content copy** karein aur paste karein
5. Right side > **Permalink** > **Custom permalink** > slug likhein (neeche table)
6. **Publish** dabayein

| File | Page Title | Custom Permalink |
|------|-----------|------------------|
| about-us.html | About Us | about-us |
| contact-us.html | Contact Us | contact-us |
| privacy-policy.html | Privacy Policy | privacy-policy |
| terms-of-service.html | Terms of Service | terms-of-service |
| disclaimer.html | Disclaimer | disclaimer |

**Note:** Permalink bilkul same rakhna zaroori hai — theme ke footer links inse match karte hain.
